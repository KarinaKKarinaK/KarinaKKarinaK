<img src="./hd-about-this-page.svg" width="620" alt="about this page"/>

Every graphic here is generated inside this repository, not embedded from<br>
anyone else's server. The stat graphics and section headings are drawn by<br>
[a scheduled action](.github/workflows/stats.yml) straight from the GitHub GraphQL API, once a day,<br>
committing only what changed. Nothing here can rate-limit or go dark.

They animate with SMIL inside the SVG, because GitHub strips scripts from<br>
READMEs. The headings are SVGs for the same reason: GitHub also strips CSS,<br>
so an image is the only way to put this page's own typeface on them. The<br>
typeface is [JetBrains Mono](scripts/fonts), subset per graphic and inlined as base64.

Language totals cover public repositories only. `year.svg` draws the year at<br>
one character per day: `:` `+` `#` `@`, quiet to loud.

Based on the self-generating profile approach by [andriidrok1](https://github.com/andriidrok1/andriidrok1).
